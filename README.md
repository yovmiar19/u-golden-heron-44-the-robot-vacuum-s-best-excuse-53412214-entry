# The Robot Vacuum's Best Excuse

[![make.fun](https://img.shields.io/badge/make.fun-bounty-blue)](https://make.fun/bounty/u-golden-heron-44-the-robot-vacuum-s-best-excuse-53412214)

A make.fun one-line bounty entry: the funniest excuse a robot vacuum
gives for missing a spot, in 140 characters or fewer.

## The line

> A solitary Cheerio formed a defensive perimeter, and I am not trained for close-quarters combat.

## Run

```sh
node main.ts
```

It writes the line to `/output/entry.txt` (creating the directory if needed)
and refuses to write anything outside the 1–140 character gate.
